# HPN Explorer: ਲਾਈਵ ਕਰਨ ਦੀ ਗਾਈਡ (ਪੰਜਾਬੀ)

ਇਹ ਸਾਈਟ ਹੁਣ ਸੁਰੱਖਿਅਤ ਹੈ: Gemini ਦੀ ਗੁਪਤ ਕੁੰਜੀ (API key) ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਨਹੀਂ ਜਾਂਦੀ, ਸਿਰਫ਼ ਸਰਵਰ ਫੰਕਸ਼ਨ (`api/chat.js`) ਵਿੱਚ ਰਹਿੰਦੀ ਹੈ।

## ਲਾਈਵ ਕਰਨ ਦੇ ਕਦਮ (ਮੁਫ਼ਤ, Vercel ਨਾਲ)
1. ਇਸ ਫੋਲਡਰ ਨੂੰ GitHub 'ਤੇ ਨਵੀਂ ਰਿਪੋਜ਼ਿਟਰੀ ਵਿੱਚ ਅੱਪਲੋਡ ਕਰੋ।
2. vercel.com 'ਤੇ GitHub ਨਾਲ ਲੌਗਇਨ ਕਰੋ, "Add New → Project" ਚੁਣ ਕੇ ਇਹ ਰਿਪੋਜ਼ਿਟਰੀ ਚੁਣੋ।
3. ਡਿਪਲੌਏ ਤੋਂ ਪਹਿਲਾਂ "Environment Variables" ਵਿੱਚ ਨਾਮ `GEMINI_API_KEY` ਤੇ ਆਪਣੀ ਨਵੀਂ Gemini ਕੁੰਜੀ ਪਾਓ।
4. "Deploy" ਦਬਾਓ। ਕੁਝ ਮਿੰਟ ਵਿੱਚ ਲਿੰਕ ਮਿਲ ਜਾਊ।
5. ਆਪਣਾ ਡੋਮੇਨ (ਜਿਵੇਂ hpnexplorer.in) Vercel ਦੀ Settings → Domains ਵਿੱਚ ਜੋੜੋ।

## ਜ਼ਰੂਰੀ ਸਾਵਧਾਨੀਆਂ
- ਕੁੰਜੀ ਕਦੇ ਵੀ ਕੋਡ ਜਾਂ GitHub ਵਿੱਚ ਨਾ ਲਿਖੋ। ਪੁਰਾਣੀ ਕੁੰਜੀ ਕਿਤੇ ਖੁੱਲ੍ਹੀ ਰਹੀ ਹੋਵੇ ਤਾਂ ਨਵੀਂ ਬਣਾ ਲਓ।
- Google AI Studio ਵਿੱਚ ਆਪਣੀ ਕੁੰਜੀ 'ਤੇ ਵਰਤੋਂ ਦੀ ਹੱਦ (quota/billing limit) ਲਾ ਦਿਓ।
- ਡਾਟਾ ਵਿੱਚ ਤਸਵੀਰਾਂ ਅਜੇ ਨਕਲੀ (picsum) ਹਨ। ਲਾਈਵ ਤੋਂ ਪਹਿਲਾਂ ਅਸਲੀ ਫੋਟੋਆਂ ਨਾਲ ਬਦਲੋ।
- ਜਾਣਕਾਰੀ (ਤਾਰੀਖਾਂ, ਦੂਰੀਆਂ) ਭਰੋਸੇਯੋਗ ਸਰੋਤਾਂ ਤੋਂ ਪੱਕੀ ਕਰੋ।

## ਕੰਪਿਊਟਰ 'ਤੇ ਚਲਾਉਣਾ (ਡਿਵੈਲਪਰਾਂ ਲਈ)
- `npm install` ਫਿਰ `npm run dev` (ਸਾਈਟ ਚੱਲੂ, ਚੈਟ ਲਈ `vercel dev` ਵਰਤੋ ਤੇ `.env.local` ਵਿੱਚ `GEMINI_API_KEY` ਰੱਖੋ)।
- `npm run build` ਨਾਲ ਲਾਈਵ ਵਰਜ਼ਨ ਬਣਦਾ ਹੈ।

## ਕੀ ਬਦਲਿਆ ਗਿਆ
- ਕੁੰਜੀ ਬ੍ਰਾਊਜ਼ਰ ਕੋਡ ਵਿੱਚੋਂ ਹਟਾਈ, ਚੈਟ ਹੁਣ `/api/chat` ਰਾਹੀਂ।
- Tailwind CDN ਤੇ esm.sh ਹਟਾ ਕੇ ਸਹੀ ਬਿਲਡ ਪ੍ਰਣਾਲੀ ਲਾਈ। ਗੁੰਮ `index.css` ਬਣਾਈ।
- ਹਰ ਜ਼ਿਲ੍ਹੇ ਦਾ ਵੱਖਰਾ ਲਿੰਕ: `/district/amritsar` ਆਦਿ।
- ਦੋ ਭਾਸ਼ਾਵਾਂ: ਉੱਪਰ ਸੱਜੇ EN / ਪੰਜਾਬੀ ਬਟਨ। ਮੀਨੂ, ਸ਼੍ਰੇਣੀਆਂ, ਜ਼ਿਲ੍ਹਿਆਂ ਦੇ ਨਾਮ ਤੇ ਚੈਟ ਦੋਵਾਂ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਹਨ। ਚੈਟ ਚੁਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਜਵਾਬ ਦਿੰਦੀ ਹੈ। ਥਾਵਾਂ ਦੇ ਵੇਰਵੇ (descriptions) ਅਜੇ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਹਨ।
- ਪੰਜਾਬੀ ਵੇਰਵੇ: ਸਾਰੇ 24 ਜ਼ਿਲ੍ਹਿਆਂ ਦੀਆਂ ਟੈਗਲਾਈਨਾਂ ਤੇ ਸਾਰੀਆਂ 138 ਥਾਵਾਂ ਦੇ ਵੇਰਵੇ ਪੰਜਾਬੀ ਵਿੱਚ (ਫਾਈਲ `pa-content.ts`)। ਕੋਈ ਵੇਰਵਾ ਗੁੰਮ ਹੋਵੇ ਤਾਂ ਆਪੇ ਅੰਗਰੇਜ਼ੀ ਦਿਸਦਾ ਹੈ। ਥਾਵਾਂ ਦੇ ਨਾਮ ਅਜੇ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਹਨ। ਅਨੁਵਾਦ ਮੂਲ ਅੰਗਰੇਜ਼ੀ ਵੇਰਵਿਆਂ ਤੋਂ ਹੈ, ਤੱਥਾਂ ਦੀ ਪੁਸ਼ਟੀ ਅਜੇ ਬਾਕੀ ਹੈ।

## ਅਸਲੀ ਤਸਵੀਰਾਂ ਕਿਵੇਂ ਪਾਉਣੀਆਂ
1. `IMAGES-CHECKLIST.csv` ਨੂੰ Excel/Google Sheets ਵਿੱਚ ਖੋਲ੍ਹੋ। ਇਸ ਵਿੱਚ 24 ਜ਼ਿਲ੍ਹਿਆਂ ਤੇ 138 ਥਾਵਾਂ ਦੀ ਸੂਚੀ ਹੈ, ਹਰ ਇੱਕ ਲਈ ਫਾਈਲ ਦਾ ਨਾਮ ਲਿਖਿਆ ਹੈ।
2. ਹਰ ਥਾਂ ਦੀ ਫੋਟੋ ਇਸ ਨਾਮ ਨਾਲ `public/images/places/` ਵਿੱਚ ਰੱਖੋ (ਜ਼ਿਲ੍ਹੇ ਦੀ ਮੁੱਖ ਫੋਟੋ `public/images/districts/` ਵਿੱਚ)। ਜਿਵੇਂ `amritsar-golden-temple.jpg`।
3. ਫੋਟੋ ਦਾ ਆਕਾਰ ਲਗਭਗ 800x600, JPG ਤੇ 200 KB ਤੋਂ ਘੱਟ ਰੱਖੋ, ਤਾਂ ਕਿ ਸਾਈਟ ਤੇਜ਼ ਖੁੱਲ੍ਹੇ।
4. ਜਿਹੜੀ ਫੋਟੋ ਨਹੀਂ ਹੋਵੇਗੀ, ਉੱਥੇ ਸਾਦੀ ਨਾਰੰਗੀ ਪਲੇਸਹੋਲਡਰ ਤਸਵੀਰ ਦਿਸੂ (ਟੁੱਟੀ ਤਸਵੀਰ ਨਹੀਂ)। ਇਸ ਲਈ ਤੁਸੀਂ ਹੌਲੀ-ਹੌਲੀ ਪਾ ਸਕਦੇ ਹੋ।
5. ਸ਼ੀਟ ਦੇ ਆਖ਼ਰੀ ਖਾਨੇ ਵਿੱਚ ਫੋਟੋਗ੍ਰਾਫ਼ਰ/ਸਰੋਤ ਦਾ ਨਾਮ ਲਿਖਦੇ ਜਾਓ।
